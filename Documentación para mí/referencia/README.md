# Referencia por archivo

Abre primero el capítulo de la aplicación que quieres retomar y luego usa este índice para ir al archivo. Las fichas enlazan el origen y explican para qué existe. En los módulos de código se destacan entradas, dependencias o contratos según el tipo de módulo. En los recursos visuales se documenta su función y, cuando corresponde, su variante.
