# Referencia de migraciones del runtime

Las mismas migraciones describen el runtime de desarrollo, staging y producción. Sigue la secuencia del nombre de archivo y la versión registrada en cada base. Cuando un objeto aparezca varias veces, busca su última definición y las migraciones de RLS, grants y vistas que lo tocan. Una definición histórica explica cómo se llegó al modelo actual.

Los nombres `20250229_...`, `20250230_...` y `20260332_...` contienen secuencias que parecen fechas fuera del calendario. Son parte del identificador versionado. Algunos comentarios internos reflejan un nombre anterior. La comprobación útil para una entrega compara el identificador de archivo con el historial SQL aplicado en el entorno.
