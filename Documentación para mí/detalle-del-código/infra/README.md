# Infraestructura, configuración y estilos por archivo

[Volver al índice de código](../README.md) · [Mapa operativo de versionado](../../07-versionado-y-despliegue.md) · [Guía Android](../../04-android.md)

Este apartado relaciona las declaraciones ejecutables y estructurales de infraestructura con su consumidor. En los archivos JavaScript se muestran funciones, parámetros, dependencias, llamadas y puntos de contacto conocidos. En CSS, cada entrada describe un selector o directiva y las clases de propiedades que controla. Los workflows se organizan por evento, job y paso.
